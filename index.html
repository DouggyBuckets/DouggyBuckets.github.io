~/projects/spun

Spun

A social rating & review app for music — built solo, end to end

A Letterboxd-style diary for music: rate and review albums and songs, build ranked lists, follow other listeners, and discover what's popular. I designed and built the full stack myself — a REST API over a normalized Postgres schema, a React Native mobile client shipping to the App Store and Play Store, and the infrastructure behind both.

Node.js Express TypeScript PostgreSQL React Native Expo JWT Zod Fly.io
  • Architected a 40+ endpoint REST API over a normalized Postgres schema (15+ tables) with Zod request validation and JWT/bcrypt authentication, enforcing data integrity across a social graph of ratings, reviews, lists, and follows
  • Integrated the Spotify Web API for catalog metadata with a Postgres-backed caching layer that persists data on first lookup, cutting redundant external calls and keeping pages fast on repeat visits
  • Built the React Native (Expo) mobile client with a custom design system and optimistic UI updates, then shipped signed builds via EAS Build and implemented account deletion, blocking, and reporting flows required for app store approval
